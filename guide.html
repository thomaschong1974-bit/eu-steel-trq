2TRQ 配额追踪器怎么用Using the TRQ quota tracker

打开链接、输入口令进入。左侧是九节导航，从上到下：Open the link, enter the code. The left sidebar has nine sections, top to bottom:

① 配额看板 — 期间 + KPI + 热力图① Dashboard — period + KPIs + heatmap

顶部先选期间：配额按季度开放，2026 Q3（7–9 月）标 LIVE 是当前活跃季。KPI 一行给出：期间配额量、已用量、总体占用率、昨日消耗、临界数、已用尽数。下方热力图是核心——行=产品类别、列=原产地，格子颜色就是那一国那一类的占用率，交叉差异一眼看穿（比如某国某类已红=用尽，但换个来源还有余量）。悬停看订单号明细，点任意格子直接跳到下方追踪表并套用筛选。 Pick a period first: quotas open quarterly; 2026 Q3 (Jul–Sep) marked LIVE is the current one. The KPI row shows period quota, used, overall %, yesterday's draw-down, critical count, exhausted count. The heatmap below is the centrepiece — rows = product category, columns = origin, cell colour = that origin×category's % used, so cross-differences pop (one origin exhausted while another has room). Hover for order-number detail; click any cell to jump to the tracker table with that filter applied.

状态配色：Status colours: 充裕 <70%Safe <70% 偏紧 70–90%Warning 70–90% 临界 90–100%Critical 90–100% 已用尽 ≥100%Exhausted ≥100%

② 配额追踪表 — 283 个订单号明细② Tracker table — all 283 order numbers

每行一个配额订单号：类别、原产地、类型、订单号、配额量、剩余余额、已用量、Δ 日均、占用率、状态。 One row per quota order number: category, origin, type, order #, quota, balance, used, Δ/day, % used, status.

  • 剩余余额是官方固定数据（每日从 TARIC 同步），表内不可改。Balance is fixed official data (synced daily from TARIC); not editable in the table.
  • Δ 日均显示每天消耗速度，下方给"预计 MM-DD 用尽"；预计撑不到季末的标红。Δ/day shows the daily draw-down and an "est. runout MM-DD"; red if it won't last the quarter.
  • 点红色订单号可直达官方 TARIC 查询页核对（订单号与原产地已带好）。Click the red order number to verify on the official TARIC page (order & origin pre-filled).
  • 上方工具栏：搜索（国家/类别/订单号）、类别下拉、类型与状态筛选块。Toolbar above: search (country/category/order), category dropdown, type & status filter chips.

③ 配额外成本测算③ Out-of-quota cost estimator

两种模式：按余额自动拆分（选订单号、输计划出货量，按当前余额拆出配额内/外）；自定义拆分（直接输配额内、配额外各多少吨）。超出部分按 50% 配额外关税算额外成本。注意余额全 EU 共享、先到先得，清关时点实际余额可能更低。 Two modes: Auto (by balance) — pick an order & planned volume, split by current balance; Custom split — enter in-quota and out-of-quota tonnages directly. Excess is costed at the 50% out-of-quota duty. Balances are EU-wide, first-come-first-served — the number at clearance may be lower.

④–⑨ 政策动态 · 时间线开闸日历 · 数据速查 · 方法论 · 说明 · 来源④–⑨ Policy · timeline & opening calendar · data tables · methodology · guide · sources

政策卡与顶部滚动快讯讲最新法规动态；时间线含下一次季度开闸倒计时；数据速查有三张折叠表（按类别、按原产地、全部 283 行含 MFN/FTA 拆分）；方法论把每个公式口径写清。顶部"✦ 互动引导"按钮会带你走一遍。 Policy cards + the scrolling ticker cover the latest regulation news; the timeline includes a countdown to the next quarterly opening; data tables give three collapsible tables (by category, by origin, all 283 rows incl. MFN/FTA split); methodology spells out every formula. The "✦ Tour" button at the top walks you through it.

3CBAM 成本计算器怎么用Using the CBAM cost calculator

1
选年份与季度——季度决定证书价（欧委会季度公布；未公布的季度显示"价格未公布"）。Pick year & quarter — the quarter sets the certificate price (published quarterly by the Commission; unpublished quarters show "not published").
2
选原产地与 HS 编码 / 生产路线——工具带出该口径的分国别默认排放值。Pick origin and HS code / production route — the tool pulls the per-origin default emission value.
3
右侧即时给出每吨 CBAM 成本与拆解（SEE、基准值扣减、证书数、证书价）。下方还有七条路线对比、全产业链拆解、政策、数据速查。The right panel instantly shows CBAM cost per tonne and the breakdown (SEE, benchmark deduction, certificates, price). Below: 7-route comparison, value-chain breakdown, policy, data tables.
口径提醒：TRQ 与 CBAM 并行叠加——配额内进口也要缴 CBAM，配额外再加 50% 关税。两个工具配合用：TRQ 追踪器看关税、CBAM 计算器看碳成本。 Note: TRQs stack with CBAM — in-quota imports still pay CBAM, out-of-quota adds the 50% duty. Use both together: the TRQ tracker for the duty, the CBAM calculator for the carbon cost.

4每日自动更新是怎么运作的How the daily auto-update works

你不用手动做任何事——一套云端定时任务每天替你跑：You don't do anything by hand — a set of scheduled cloud tasks runs it for you:

1
每天 09:30（吉隆坡时间），云端自动启动"配额每日同步"任务。Every day at 09:30 (Kuala Lumpur time), the "daily quota sync" task starts automatically in the cloud.
2
它通过你电脑的 Chrome 打开官方 TARIC，抓全部 283 个订单号的最新余额，校验（必须 283 条、无余额超配额）。It opens the official TARIC through your computer's Chrome, scrapes all 283 balances, and validates (must be 283, no balance above quota).
3
更新你桌面的内部 artifact，并把新的 trq_balances.json 提交到 GitHub 仓库。It updates the internal artifact on your desktop and commits the new trq_balances.json to the GitHub repo.
4
网站访客下次打开就自动看到最新数据——网页每次加载都去拉那个 JSON（带时间戳绕过缓存），或点右上角"⟳ 刷新数据"。Website visitors see the latest data on next open — the page fetches that JSON on every load (cache-busted), or click "⟳ Refresh" top-right.

CBAM 计算器不同：它内置的是欧委会官方公布的季度证书价（现为 2026 Q1 €75.36 / Q2 €75.28），未公布的季度显示"价格未公布"——我们绝不臆测碳价。每周一有一个监测任务检查官方是否公布了新一季证书价，一旦公布就提醒 Thomas 手动更新一次（对我说"把 CBAM 计算器的某季度证书价更新为 €X"即可）。政策扫描每周一、季度开闸日核验、12 月分配细则续期监控也都各自在跑。 The CBAM calculator is different: it carries the Commission's officially published quarterly certificate price (now 2026 Q1 €75.36 / Q2 €75.28); unpublished quarters show "price not released" — we never guess the carbon price. A weekly monitor checks each Monday whether a new quarter's price has been published and, when it is, prompts Thomas for a one-time manual update (just tell me "update the CBAM calculator's Qx certificate price to €X"). A weekly policy scan, a quarterly opening-day check, and a December renewal watch also run.

5怎么确保它每天真的更新（重点）How to ensure it actually updates daily (important)

任务每天都会触发；但它要靠你的电脑去抓官方数据，所以能不能跑完，取决于那个时点你的电脑在不在线。 The task fires every day; but it drives your computer to scrape the official data, so whether it completes depends on your computer being online at that moment.

每天 09:30 前后，这三样请同时保持在线：Around 09:30 daily, keep these three online at the same time:

  • 桌面端 Claude 应用开着（云任务通过它连到你的电脑）。The Claude desktop app is open (the cloud task reaches your computer through it).
  • Chrome 开着，且 Claude 浏览器扩展已连接（登录的是同一个 claude.ai 账号）。Chrome is open with the Claude browser extension connected (same claude.ai account).
  • Chrome 里已登录 GitHub（thomaschong1974-bit）——提交数据要用。You're logged into GitHub (thomaschong1974-bit) in Chrome — needed to commit the data.

电脑不用一直开，只要覆盖 09:30 那几分钟即可；抓取约 2–3 分钟。Your computer needn't stay on all day — just cover the few minutes around 09:30; the scrape takes ~2–3 min.

如果那个时点离线会怎样？What if you're offline then?

  • 任务照常触发，但连不上 Chrome → 自动跳过、不报错，并给你推送通知"今日跳过：Chrome 未连接"。你会知道。The task still fires but can't reach Chrome → it skips gracefully and sends a push notification "skipped today: Chrome not connected". You'll know.
  • 网站不会显示错误——继续显示上一次成功的数据（侧栏日期就是最后成功日）。The website never errors — it keeps showing the last successful data (the sidebar date = last successful day).

怎么知道今天更新成功了？How to confirm today succeeded

  • 收到推送总结（占用率 / 消耗 / 用尽清单）。You get a push summary (% used / draw-down / exhausted list).
  • 网站侧栏显示"已更新 · 今天日期"。The website sidebar shows "Updated · today's date".
  • GitHub 仓库能看到当天的 Daily TRQ balances 提交。The GitHub repo shows a Daily TRQ balances commit for today.

漏了一天 / 想立刻更新，怎么补？Missed a day / want it now?

随时在对话里对我说 "刷新配额"——我立刻抓一遍最新数据、更新 artifact 并提交 GitHub。数据是当日累积的官方余额，补跑一次即可补上，不会丢。 Just tell me "refresh the quota" in chat anytime — I'll immediately scrape the latest, update the artifact and commit to GitHub. The official balances are cumulative, so one catch-up run fills the gap; nothing is lost.

小知识：官方 TARIC 周末不更新，所以周六日的数据与周五相同是正常现象，不是故障。数据日期以页面"Last tariff QUOTA update"为准。 Note: official TARIC doesn't update on weekends, so Sat/Sun matching Friday is normal, not a fault. The data date follows the page's "Last tariff QUOTA update".

6常见问题FAQ

Q：网站是公开的吗？密码安全吗？Q: Is the site public? Is the password secure?

GitHub Pages 免费版仓库是公开的，所以密码只是"礼貌性遮挡"，不是真安全。里面都是公开法规数据，没问题；但别把敏感内容放进去。 Free GitHub Pages repos are public, so the password is only a courtesy screen, not real security. The content is all public regulatory data, which is fine — just don't put anything sensitive behind it.

Q：客户打开需要装什么吗？Q: Do clients need to install anything?

不用。任何浏览器打开链接、输口令即可，手机也行。数据由网站自动拉取，客户永远看到你这边最后成功更新的版本。 No. Any browser, open the link, enter the code — phones too. The site fetches data automatically; clients always see your last successfully-updated version.

Q：283 个订单号本身会变吗？Q: Do the 283 order numbers themselves change?

只在分配法规变更时变。IR 2026/1457 适用到 2026-12-31；2027 Q1 起需要新法规——12 月的专项监控任务会盯着，届时我按新法规重建数据集。日常余额更新不动订单号。 Only when the allocation regulation changes. IR 2026/1457 applies to 31 Dec 2026; 2027 Q1 needs a successor act — the December watch task tracks it, and I'll rebuild the dataset then. Daily balance updates never touch the order numbers.

Q：CBAM 证书价的 Q3/Q4 为什么显示"未公布"？Q: Why do CBAM Q3/Q4 prices show "not published"?

证书价由欧委会按季度公布，我们绝不臆测碳价。每周任务确认官方公布后才填入。 The certificate price is published quarterly by the Commission and we never guess it. The weekly task fills a quarter in only once officially released.
